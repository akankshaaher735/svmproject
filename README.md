# 🤖 SVM Machine Learning Prediction App

A modern and interactive Machine Learning web application powered by **Support Vector Machine (SVM)** and Python Flask.

This application uses a trained SVM model to generate predictions through a user-friendly interface featuring a premium Mint Turquoise (#98E8DE) theme, smooth animations and interactive visual elements.

## ✨ Features

- 🤖 SVM-based Machine Learning predictions
- 🎨 Modern Mint Turquoise UI (#98E8DE)
- 💎 Glassmorphism design with elegant shadows
- ⚡ Smooth animations and interactive effects
- 📊 Attractive prediction result visualization
- 📜 Prediction history tracking
- 📥 Download prediction history as CSV
- 📱 Responsive design for different devices
- 🌙 Dark/Light mode toggle
- 🔔 Interactive notifications and validation

## 🛠️ Technologies Used

- Python
- Flask
- Scikit-learn
- HTML
- CSS
- JavaScript
- Pickle
- Gunicorn
